Ambiente de Automação e Gerenciamento com Ansible

Este servidor (SwebDMZ01) integra o projeto de TCC:
"Automação do Gerenciamento de Servidores com Ansible", desenvolvido por Evellyn Patricia Adolfo e Marcos Donato.

Serviços neste Host

  • Servidor Web público (Nginx)
  • Página institucional estática

Segmentação do Laboratório

  • REDE TI (10): Estações Linux
  • REDE FIN (20): Estações Windows
  • REDE SERVER (100): AD, Ansible, Samba, NTP
  • REDE DMZ (200): Web e DNS público
  • REDE MGMT (50): Gerenciamento seguro

⚠️ Ambiente acadêmico — sem dados sensíveis.
